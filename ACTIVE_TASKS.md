## 1. Текущие завершённые и верифицированные задачи

### **[PREVIEW-HOST-CHECK-2026-09-16] Восстановление отображения приложения: политика хостов dev-сервера Vite (инцидент «приложение не отображается»)**

* **Статус:** `G4_DEVELOPMENT_COMPLETED` (воспроизведение «до/после» + regression-страж; андон `A-0010`, карточка `TPS-0011`, кайдзен `K-0013`, потеря `M-0014`).
* **Симптом:** превью открывается пустым — ни интерфейса, ни спиннера, ни клиентской ошибки.
* **Первопричина (измерена, не предположена):** dev-сервер Vite отвечал `403 Blocked request. This host ("<preview-host>") is not allowed.` **до** SPA-мидлвари, поэтому отклонялись и документ, и модули: код приложения до браузера не доходил вообще. Настройка `allowedHosts` в `server.ts` была **opt-in** (`process.env.VITE_ALLOWED_HOSTS === "true" ? true : undefined`), а переменную не выставляет ни платформа превью, ни скрипты, ни `.env*` — эффективным оставался дефолт Vite `[]` («разрешены только localhost/IP»). Проверка хоста появилась в Vite 6.0.9+/5.4.12+/4.5.6+ (защита от DNS-rebinding), и в проект она пришла апгрейдом `e5bd034` (2026-08-17, `vite ^5.3.4` → `^8.2.1`) — то есть с этого дня канал превью не работал вообще, а гейты `lint`/`test`/`build` и деплой Pages оставались зелёными, потому что **ни один из них не проходит через транспорт dev-сервера**.
* **Что сделано:** политика вынесена в единый модуль `server/devHostPolicy.ts` (`resolveDevAllowedHosts`) и стала **opt-out**: пустая переменная → проксированные хосты разрешены, `false` → строгий режим (localhost/IP), список → явные суффиксы; та же политика подключена к `server.allowedHosts` и `preview.allowedHosts` в `vite.config.ts`; при старте dev-сервера печатается `Dev server allowed hosts: …`; новый страж `server/devHostPolicy.test.ts` (10 тестов) поднимает **настоящую** Vite-мидлварь и делает HTTP-пробу с проксированным `Host`, включая контрольную пробу строгого режима (`403`) — тест, который не может покраснеть, защитой не считается.
* **Проверка (фактические прогоны):** `curl -H 'Host: <preview-host>' /` → было `403`, стало `200`; `/src/main.tsx` → `200` (ESM); обход графа модулей dev-сервера → **208/208 запросов `200`**; реальный `App` без моков отрендерен в jsdom (DOM 374 447 символов, 0 `console.error`) — то есть приложение было целым и не отображалось только из-за входа; `npx vitest run server/devHostPolicy.test.ts` → 10/10; `npx tsc --noEmit` → 0; остальные гейты — в карточке `TPS-0011`.
* **Граница доверия:** правка касается **только dev-канала**. `vite build` не читает `server.*`/`preview.*`, `npm start` отдаёт статику из Express без Vite, Pages получает собранный бандл — продовый периметр не менялся. Доступность опубликованного сайта из песочницы **не проверялась** (внешний HTTPS-эгресс к `a1dmitry.github.io` недоступен — TLS-ошибка соединения), это ограничение среды, а не факт о сайте. `allowedHosts: true` в dev осознанно отключает проверку хоста (dev по определению стоит за доверенным прокси площадки), возможность сужения сохранена и задокументирована в `.env.example`.
* **Свидетельство:** [`docs/05-evidence/architecture/incident-2026-09-16-preview-not-displaying.md`](docs/05-evidence/architecture/incident-2026-09-16-preview-not-displaying.md) (разбор, временная линия, отброшенные гипотезы, ручное воспроизведение), A3 [`docs/00-governance/tps/A3-ANDON-0010.md`](docs/00-governance/tps/A3-ANDON-0010.md).
