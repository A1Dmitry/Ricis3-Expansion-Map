# RICIS Expansion Map — интерактивная карта сингулярностей, зависимостей и доказательных границ

**RICIS Expansion Map** — открытая исследовательская среда для визуального изучения математических задач, выражений, сингулярностей и цепочек зависимостей по методологии RICIS-III. Приложение объединяет интерактивную **3D-карту**, доступный **режим списка**, структурную диагностику выражений, интеграцию с **C# Ricis.Core** и четко очерченную границу между гипотезой, вычислением и внешней Lean kernel верификацией.

## Назначение и Сценарии использования

Карта помогает исследователю наглядно увидеть структуру сложной математической задачи, происхождение результата, трассу преобразований и необходимый следующий шаг верификации.

| Роль | Первый полезный сценарий | Практический результат |
| :--- | :--- | :--- |
| **Исследователь RICIS-III** | Найти сингулярность, раскрыть связанные узлы и проследить преобразования. | Карта зависимостей, семантический контекст, trace и следующие исследовательские действия. |
| **Математик или Студент** | Изучить задачу в интерактивном 3D-пространстве или переключиться в доступный плоский список. | Наглядная структура материала, фильтры, карточки и доступная навигация. |
| **Рецензент / Формализатор Lean** | Открыть proof-артефакт конкретного узла и проверить доказательные границы. | Разделение черновика, внешнего Lean-кода, доверенного контракта и kernel evidence. |
| **Разработчик Ricis.Core / TS** | Запустить проект локально, проверить Core-подключение и запустить автотесты. | Строгий Core-first bridge, типизированное восстановление и чистый CI-готовый репозиторий. |

## Ключевые возможности приложения

### 1. Исследовательская 3D-карта и доступный каталог
Карта отображает проблемные узлы, связи, научные зоны и пути зависимостей в интерактивной WebGL-сцене. Поддерживаются поиск, фильтрация и навигация. Если WebGL недоступен или требуется классическая навигация, доступен семантически эквивалентный **режим списка**.

### 2. Работа с сингулярностями RICIS-III
Поддерживается визуальное исследование точек вида `0/0`, `∞/∞`, `∞ − ∞`, `0·∞`, полюсов, фактор-сокращений и связанных структурных форм. Нормативный порядок вычислений строго следует правилам RICIS-III:
$$\text{L0} \to \text{L1} \to \text{SP2} \to \text{Локальная } O(1)\text{-редукция} \to \text{A1/A4} \to \text{SP3} \to \text{SP4} \to \text{A5/A6/A7}$$

### 3. Core-first вычисления и понятное восстановление
Вычисление сингулярностей производится через **Ricis.Core** (C# API или C# WASM). Приложение предоставляет детальный интерфейс восстановления (Core Recovery Diagnostics), если внешний рантайм недоступен, обеспечивая полную прозрачность вычислений без маскировки ошибок локальными заглушками.

### 4. Локальный структурный анализ
Встроенный **Local RICIS Analyzer** предназначен для непрерывного исследовательского workflow, когда Core временно недоступен. Он использует безопасную грамматику и детерминированно выполняет базовые редукции выражений без исполнения произвольного текста пользователя.

### 5. Proof Workspace и честная граница Lean
В консоли доказательств (**RICIS Proof & Singularity Console**) можно изучать трассировки преобразований, просматривать сгенерированный Lean-код и проверять статус верификации. Карта четко разграничивает локальные гипотезы, Core-вычисления и реальные доказательства, прошедшие Lean kernel проверку (`Lean kernel verified`).
