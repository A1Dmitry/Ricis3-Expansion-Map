# RICIS3-Expansion

**Версия: v0.2.0**

Интерактивная 3D-карта проблем сингулярности (ядро RICIS-III).

## Демо (GitHub Pages)

https://a1dmitry.github.io/RICIS3-Expansion/

## Что в v0.2.0

- Отображение версии в шапке и футере (`v0.2.0`)
- IndexedDB: каждый узел — JSON-документ
- Каталог известных проблем (Clay / Nobel / commercial / reputation)
- Ядро RICIS-решаемых задач
- Автосохранение после solve

## Локальный запуск

```bash
npm install
npm run dev
```

После обновления с сервера: в UI **Сброс карты**, чтобы подтянуть новый каталог из кода.
