# RICIS Expansion Map — интерактивная карта сингулярностей, зависимостей и доказательных границ

**Версия: 0.4.120**

**RICIS Expansion Map** — открытая исследовательская среда для визуального изучения математических задач, выражений, сингулярностей и цепочек зависимостей по методологии RICIS-III. Приложение объединяет интерактивную **3D-карту**, доступный **режим списка**, структурную диагностику выражений, интеграцию с **C# Ricis.Core** и четко очерченную границу между гипотезой, вычислением и внешней Lean kernel верификацией.
