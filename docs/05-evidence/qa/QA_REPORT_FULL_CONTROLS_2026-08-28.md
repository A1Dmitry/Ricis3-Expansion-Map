## 4. Сверка выбранных данных с GitHub

Узел `real-catalog-98` в актуальном исходнике имеет заголовок «Распределение богатства Парето», описание «Концентрация капитала», состояние `unresolved` и target function `Formalize(РаспределениебогатстваПарето)`. Live отображает те же семантические данные; различие идентификатора представлено ожидаемым Base64 UI-ключом и canonical path.

Для узла «Проблема инвариантных подпространств» live отображает `Formalize(Проблемаинвариантныхподпространств)`, описание «Существует ли нетривиальное инвариантное подпространство?» и подсказку «Спектральная сингулярность оператора». Эти значения совпадают с актуальным `src/model/catalog.ts`.

## 5. Каталог калькуляторов

Каталог решённых случаев открывается и не маскирует отсутствие backend: для большинства элементов отображается `Visual calculator не настроен: calculator_base_url_missing`. Исходные тесты `calculatorExplorer.domain.test.ts` и `ricisSolutionCatalog.test.ts` прямо закрепляют такое поведение как честный `UNCONFIGURED`-результат при отсутствии calculator endpoint. Поэтому issue на основании этой индикации не публиковался: это ожидаемая конфигурационная граница, а не подтверждённая регрессия.

## Новый подтверждённый дефект: переключатель EN не переводит интерфейс

Сценарий: открыть live-карту в русской локали, нажать кнопку `EN` и повторно нажать `EN` при URL с `lang=en`.

Фактический результат: URL получает параметр `lang=en`, но интерфейс остаётся русским: `Решенные случаи калькулятора`, `Маршрут изучения мономолитов`, `Наука/поля`, названия задач, описания и русские подписи остаются без перевода. Кнопка EN не приводит к английскому пользовательскому представлению.

Ожидаемый результат: после выбора EN все переводимые элементы управления, статусы и тексты выбранного узла должны перейти на английский язык, а выбранный узел и его состояние должны сохраниться.

Статус: подтверждённый функциональный дефект, опубликован как [GitHub Issue №17](https://github.com/A1Dmitry/Ricis3-Expansion-Map/issues/17). Изменений в продуктовый код не вносилось.
