# Классическая строка меню — v0.4.220

AUDITOR: SELF (same-pipeline)

1. **ORIGINAL GOAL:** пользователь уточнил по образцу Visual Studio / Word: в строке меню и выпадающих меню подписи должны оставаться. Только панель инструментов — иконки с подсказками. Это уточнение заменяет прежнее буквальное применение «все кнопки — только иконки» к меню.
2. **RESULT:** добавлены явные варианты `icon`, `menu`, `menubar`. Верхние категории текстовые; выпадающие команды показывают иконку, подпись и существующую горячую клавишу. Меню задачи ☰ также показывает все названия; отдельный триггер ⋮ не возвращён.
3. **VERIFICATION:** TypeScript и production build проходят; 56 файлов / 268 UI-тестов проходят. В Chromium 153 проверены строка меню и выпадающие команды при ширине 1440 и 390 px. Дополнительно открыто реальное меню выбранной задачи: один триггер в шапке, все 12 доступных в этом сценарии команд имеют видимые названия.
4. **POSITIVE RESULTS:** меню больше не наследуют квадратные размеры панели инструментов; подписи переносятся внутри ограниченной ширины. Проверены стрелки, Escape с возвратом фокуса и переключение открытого меню наведением.
5. **NEGATIVE RESULTS:** build сохраняет предупреждение существующего `zenodoHttpAdapter.ts` об `import.meta` в CJS. Полный backend/domain-набор в этом такте не запускался.
6. **TUKHTA FOUND:** предыдущая трактовка подменяла классические меню рядами безымянных иконок; единая проверка квадратных размеров не подтверждала удобство меню.
7. **ROOT CAUSES:** отсутствовало разделение презентации команды в toolbar и menu.
8. **REPAIRS:** варианты презентации общего компонента, отдельные CSS-контракты, восстановленные видимые подписи и shortcuts, новые регрессионные проверки.
9. **REMAINING RISKS:** внешний рецензент отсутствует; браузерная проверка использовала fallback-карту без WebGL. Не утверждается полная визуальная проверка всех локалей и состояний.
10. **EVIDENCE:** `CompactCommandMenuBar.test.tsx`, `NodeContextMenu.test.tsx`, `NodeCardDetails.headerMenu.test.tsx`, UI-набор Vitest, локальный Chromium/Playwright. Браузерные инструменты и снимки не добавлены в зависимости или Git.
11. **FINAL STATUS:** PARTIALLY_COMPLETED по требованию независимой верификации; реализация и указанные локальные проверки выполнены.
